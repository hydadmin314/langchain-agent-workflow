# LangChain Agent Workflow

企业级 LangChain Agent 开发脚手架，支持工具调用 + LangGraph 工作流，开箱即用

## ✨ 功能特性

- 开箱即用，无需配置目录结构
- 标准化分层架构（配置/Agent/工具/提示词/记忆）
- 支持两种 Agent：
  - 传统工具 Agent (AgentExecutor)
  - 新一代 LangGraph 状态机 Agent
- 内置计算器、搜索工具
- 支持对话历史记忆
- 支持 GPT / 国内大模型无缝切换

## 🚀 快速开始

```bash
git clone https://github.com/kekko1223/langchain-agent-workflow.git
cd langchain-agent-workflow
pip install -r requirements.txt
```
