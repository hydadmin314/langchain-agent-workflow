# 中国联通互联网专线接入（沃专线类）服务协议

四、甲方应遵守国家相关的法律、法规，不得利用租用乙方的服务从事损害国家网络信息安全的行为，若甲方有违反此条规定的行为发生，乙方有权立即终止对甲方的服务，由此造成的一切损失由甲方承担；

否则，乙方有权立即停止向甲方提供服务并追回所有拖欠费用，由此造成的一切后果均由甲方承担，同时，甲方应当向乙方按照中国联通互联网专线接入业务（沃专线类）标准资费支付自开通之日到发现上述行为之日的月租之和作为违约金。

七、本协议费用包括月使用费和一次性费用，其中，月使用费包括网络使用费、接入电路通信费和IP地址费；

自本协议双方盖章签字之日起十个工作日内，甲方应将预付款（包括首账期月使用费及一次性费用）缴入乙方指定账户（如下所附）。

遵照《中华人民共和国电信条例》的规定，甲方逾期未支付通信费用，乙方有权要求其补缴费用，并按照所欠费用每日加收3‰的违约金。

甲方逾期未支付通信费用超过30日，乙方有权暂停服务。

甲方逾期未支付通信费用超过90日的，乙方有权终止服务，并有权依法追缴欠费和违约金。

乙方亦有权决定不在前述时间点（但不少于前述时间）行使暂停服务或终止服务（以下合称：停机）的权利；

如乙方（未在前述时间点行使停机的权利，乙方有权依据实际停机的时间，主张甲方欠费期间的全部通信费及违约金，甲方不得以乙方有权停机而未予停机作为拒绝支付通信费的理由；

九、如果甲方终止该协议，须提前30天书面提出协议终止申请。

甲方协议终止当月的月度使用费按照全月使用费收取。

如果甲方签约享受了乙方提供的折扣和/或优惠（包括促销和预付方式），并已承诺合同期限，甲方在合同期限内原则上可以申请移机，但不得申请终止服务、停机保号、变更付费方式、降低付费率等可能导致原合同签订金额下降的服务【注：“合同期限”自业务开通当月开始，至到期自然月最后一天终止】。

十、甲方用于经营IDC、ISP、CDN等业务时需提供增值电信业务经营许可证（附经营范围、年检情况记录表），甲方不得擅自改变使用用途，甲方变更使用用途时，应及时以书面方式告知乙方，否则乙方有权终止协议，并对此不承担任何责任。

十三、甲乙双方对本协议的具体内容负有保密责任。

未经对方事先书面同意，任何一方不得将双方的合作及本协议的具体内容披露给任何第三方。

如果一方违约，遵守协议的一方应有权通过有关司法程序或有关政府部门的行政程序获得补偿。

如果有需要通过法院或行政程序强制执行本协议的任何条款，胜诉方应有权被判定获得合理和必要的诉讼费用的赔偿，包括合理的律师费。

十七、因本协议而发生的争议，双方应首先通过友好协商解决争议。

十八、本协议自双方签字盖章之日起生效。
