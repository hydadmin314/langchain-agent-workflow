i) 商云通需连接互联网宽带使用，该宽带必须保证每个加载商云通号码的终端都必须为有上海地区 IP 地址（在上海地区申请宽带可能存在IP 地址其实不属于上海的情况，请客户注意），且至少有不少于 100Kbits/s 上下行的带宽且网络丢包率<1%、网络抖动<=60ms 和时延<60ms。若客户使用的宽带不满足前述要求，则造成的话音质量问题由客户自行承担和修复。商云通业务资费不包括宽带业务使用费。因客户欠费等非中国电信上海公司原因造成宽带停机导致商云通业务无法正常使用的，中国电信上海公司不因此而减免任何费用。若连接的互联网宽带非中国电信上海公司提供，则使用时由于宽带问题导致的话音质量不畅由客户自行联系宽带运营商进行排查，中国电信上海公司不承担责任且不因此而减免任何费用。
