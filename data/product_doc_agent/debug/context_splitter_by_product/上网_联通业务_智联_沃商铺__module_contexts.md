沃商铺

**业务介绍：**

沃商铺是上海联通面向个体工商户、小微门店推出的**光纤共享型商企宽带**，基于 PON/FTTB 光纤接入，动态 IP 为主，轻量化、低月租、快速安装，支持收银、线上接单、门店 WiFi、监控基础联网，标配路由 WiFi，可叠加企业固话、云监控、基础安全防护。

**应用场景：**

· 沿街实体店：餐饮、奶茶、便利店、服装店、美容美甲、生鲜蔬果、烟酒行

· 商场 / 专业市场档口：购物中心专柜、建材市场、花鸟市场、汽配城小店

· 社区小微服务：干洗店、宠物店、房产中介、图文打印、理疗馆

· 小型连锁单店：单门店收银系统、美团 / 饿了么接单、门店监控、顾客公共 WiFi
