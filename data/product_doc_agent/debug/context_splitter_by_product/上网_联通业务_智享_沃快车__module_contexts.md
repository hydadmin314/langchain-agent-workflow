智享（沃快车）

**业务介绍：**

沃快车（智享套餐 / 智享云宽）属于**共享型政企 DIA 互联网接入**，采用 FTTB+LAN/EPON 光纤组网，RJ45 网线入户，楼内独立 VLAN 隔离，上联联通 169 骨干城域网，**上下行对称带宽**，专门解决企业多终端办公、文件上传、视频会议卡顿痛点。

**应用场景：**

标准款支持**30–50 台办公终端**，适配中小公司全员工同时上网

1. 甲级 / 乙级写字楼中小公司：贸易、咨询、设计、广告、新媒体、财务事务所，员工 10–50 人
2. 产业园区独栋 / 分层企业：科技小微企业、软件开发、电商运营、直播工作室
3. 联合办公、共享办公室、孵化器批量办公区
4. 培训机构、律所、中介总公司（区别门店沃商铺）

不得擅自下载境外互联网的信息在国内网站上发布，不利用广告联盟等方式链接到非法网站。

(一) 应当租用获得相应经营许可证的基础电信业务经营者提供的网络接入等电信资源从事业务经营活动，不得向其他从事网站接入服务的增值电信业务经营者转租所获得的网络接入等电信资源；

不得向个人提供用于经营电信业务的电信资源或者提供网络接入、业务接入服务。

(二) 不得为未经许可或者未备案的网站提供接入或代收费等服务。

七、 对于由中国联通分配的 IP 地址，用户只有使用权，不可转让他人使用，用户退出时 IP 地址使用权自动取消。

如需使用中国联通 IP 地址进行互联网增值电信业务经营活动的，必须提供工业和信息化部颁布的相关经营资质、否则不得经营该项业务。
