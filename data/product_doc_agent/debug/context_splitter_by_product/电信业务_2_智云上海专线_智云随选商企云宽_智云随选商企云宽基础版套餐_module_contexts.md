智云随选商企云宽基础版套餐：

**产品介绍：**

上海电信**智云上海**云网融合政企宽带主力入门套餐，面向写字楼、产业园中小微企业打造的**云网一体商用宽带**，替代传统普通办公宽带，兼顾高速上网、便捷上云、轻量化企业数字化增值服务，主打高上行、稳定光纤、云应用随选开通。

**应用场景：**

### 1. 初创小微企业办公室（最核心场景）

10–50 人小型公司、联合办公、独立写字楼单间：日常网页、OA、财务系统、企业微信、邮件收发、多人同时云端文档协作，100M 上行支撑全员同步上传报表、设计文件。

### 2. 线下服务门店 / 连锁分店后台

中介门店、教育培训机构、医美、零售连锁：门店监控云端存储、客户系统云端录入、线上课程直播 / 录播上传、多门店统一后台数据同步。

### 3. 轻设计、传媒、图文工作室

平面设计、短视频剪辑、摄影工作室：批量高清素材上传天翼云盘、远程协作改稿、云端渲染轻量化文件，大上行解决素材上传卡顿痛点。

### 4. 园区中小商贸、贸易公司

进出口、货代、咨询公司：多网页后台、报关系统、跨境平台、远程视频会议、多终端同时在线，稳定带宽保障业务系统不掉线。

### 5. 远程办公 / 混合办公企业

员工居家 + 办公室混合办公：稳定访问企业云端服务器、VPN 远程内网、云电脑异地调取办公资料，智云内网降低跨网延迟。

### 6. 配套轻量化智慧安防场景

商铺 / 办公室部署天翼云眼，多路摄像头录像实时云端回存、手机远程查看，套餐配套云回看免单独购买监控宽带。
