### supplementary_info.product_intro

产品名称：**IPAMN**业务介绍：

**IPMAN（IP Metropolitan Area Network，IP 城域网专线）**，是中国电信面向政企客户推出的**城域独享光纤互联网专线**，通过点对点光纤直连电信本地 IP 城域核心骨干网，区别于普通共享企业宽带、家用宽带、跨城 MPLS VPN，主打**同一城市内高速、低时延、高安全、对称独享带宽、多固定公网 IP**，是本地大中型企业顶级互联网接入方案。

### 核心技术架构：

1. **接入方式**：纯光纤点对点独享，不共享分光资源，客户机房部署光电转换器，出 10/100M/1G/10G 以太网电口，用户端设备投入低；
2. **网络通道**：直连电信本地城域核心，不走普通公众互联网拥堵链路，部分区域叠加 CN2 精品出口优化国际访问；
3. **地址资源**：标配多个静态公网固定 IP，最大可扩容至 256 个，支持域名反向解析，可自建对外服务器；
4. **SLA 服务保障**：网络可用性 99.99%，同城时延≤5ms、低抖动、低丢包，7×24 小时政企专属运维。

## IPMAN 核心优势

1. **极致城域性能** 同城分支互联、本地服务器访问时延极低，视频会议、实时数据库、直播推流无卡顿；独享带宽不被其他用户抢占，高峰期无降速。
2. **充足公网固定 IP** 普通企业宽带仅 1 个 IP，IPMAN 可批量申请多公网 IP，满足官网、邮件服务器、小程序后端、游戏服务器、安防公网接入等多业务对外发布需求。
3. **高安全隔离**物理，逻辑独立通道，与公众互联网底层隔离，天然抵御端口扫描、广播风暴；政企、金融、政务等涉密业务首选本地互联网专线。
4. **全业务透明承载** 不限制端口、不屏蔽协议，支持 HTTP/HTTPS/FTP/数据库/视频流/ VoIP/IPsec VPN 等所有上层应用。
5. **国际访问优化（可选增值）** 搭载 CN2 精品国际出口，访问海外网站、跨境 SaaS、境外服务器丢包与时延大幅优于普通互联网专线。

**应用场景：**

### （一）互联网 / 数字科技行业（最核心场景）

1. **服务器集群对外部署** 企业官网、商城、小程序后端、API 接口服务器、云本地混合部署；多台服务器需独立公网 IP，IPMAN 批量 IP 完美适配，稳定承载线上交易、用户访问。
2. **游戏 / 直播 / 传媒文娱** 游戏区服、直播推流、短视频素材上传、4K 实时演播；对称大带宽 + 低抖动，保障高清直播、多人在线游戏不卡顿；传媒大文件素材高速上传云端。
3. **跨境电商、外贸企业** 搭配 CN2 国际精品出口，稳定访问亚马逊、独立站、海外 ERP、跨境视频会议；多 IP 用于多店铺运营，规避平台 IP 限制。
4. **IDC、算力、软件服务商** 本地机房算力节点、私有云对外出口，为下游客户提供稳定网络底座。

### （二）政务、公安、事业单位（高安全刚需）

1. **区级政府、街道办、政务服务中心** 多政务系统并行：一网通办、政务内网对外门户、视频信访、政务云访问；物理隔离专线保障群众业务系统不间断，多 IP 区分对外公示、办事、监控业务。
2. **公安、交通、城管、应急管理** 全城摄像头视频流回传、应急指挥大屏、实时数据上报；极低时延保障视频监控无延迟，专线隔离杜绝监控数据泄露。
3. **高校、中小学、职教园区** 多校区同城互联、在线教学平台、校园官网、选课系统、图书馆数字资源；上万师生并发上网，对称带宽保障线上考试、直播授课稳定。

### （三）金融、保险、律所（安全 + 稳定双要求）

1. 证券营业部、保险分公司、小额贷款、律所事务所 实时行情交易系统、客户线上投保、财务报税系统、远程法务视频；低时延保障交易无延迟，隔离专线防止客户资金、隐私数据泄露；多 IP 区分交易端、客服官网、内部 OA 外网通道。

### （四）制造业、工厂、智能制造

1. 大型厂区、工业园区、汽车 / 电子 / 化工智造企业 工业物联网传感器数据上传、MES 生产管理系统、厂区安防监控、设备远程运维；7×24 小时不间断数据采集，独享带宽避免生产数据拥堵断连；同城多厂区通过 IPMAN 高速互通。
2. 能源、水务、燃气集团 管网远程监测、智能抄表、应急调度平台，实时采集海量设备传感数据。

### （五）医疗、医院、体检中心

三甲医院、连锁医疗机构、体检机构： 远程会诊 4K 高清视频、电子病历云端同步、线上挂号系统、医疗设备数据上传；低时延保障异地专家实时诊疗，专线隔离保护患者病历隐私。

### （六）商业地产、文旅、物流仓储

1. **商场、酒店、景区、写字楼** 全屋 WiFi 运营、客流统计摄像头、线上购票系统、酒店 PMS 管理；大带宽支撑数万游客 / 顾客同时上网。
2. **大型物流园区、冷链仓储** 货车 GPS 实时定位、仓储 WMS 管理系统、智能货架传感器数据、快递面单云端打印；同城多仓高速数据互通。

### （七）集团总部、大型连锁企业同城多点组网

同一城市内总部 + 多家分公司、门店： 通过 IPMAN 光纤实现**同城高速内网互通 + 统一互联网出口**，搭建企业 IPSec VPN，总部统一管控 OA、财务、ERP 系统，相比普通宽带同城互联速度提升数倍。

### （八）安防、弱电集成商项目配套

智慧城市项目、园区整体智能化改造：为监控平台、智慧停车、门禁系统提供稳定公网出口，多 IP 分配给不同子系统独立上线。

### supplementary_info.application_materials

IPMAN申请提示
一、提交基本信息，获取DK（方案）编号
 1、填写IPMAN申请表和IP地址报备表，电子格式提交；
 2、IPMAN申请时≥16个IP地址的，需提供拓扑图，加盖公章的扫描件；
 3、营业执照复印件，加盖公章的扫描件，
 4、经办人身份证正反面复印件，加盖公章的扫描件；
 5、提供电信光箱号或者参考编号；（客户最好能提供，无法提供的，电信会上门勘察）

二、正式合同
 1、客户确认合同内容，先不要盖章；
 2、确认后回复；
 3、电信出正式合同后（水印版）；

三、申请手续和合同盖章，提交录单
1、IPMAN申请表，填写完整打印，加盖公章；
2、IP地址报备表，填写完打印，加盖公章；
3、IPMAN申请时大于等于16个IP地址的，拓扑图加盖公章；
4、客户代拍授权委托书，填写加盖公章；
5、营业执照复印件一份，加盖公章；
6、经办人身份证正反面复印件五份，加盖公章；
7、电信水印合同，一式四份，签字，加盖公章，每份加盖骑缝章。

其他：
1、如遇到同地址同户名有存量宽带的需要提供《承诺函》，填写好打印盖公章
2、如遇到商机冲突，在“商机冲突客户授权书”上盖公章
