1. **本规则套餐协议期为一年自客户所选择的基础套餐内宽带产品完工之次月1日起算，本套餐为年付方式，付费周期从宽带产品完工之次月开始，首月资费下述标准按天折算：****50M/50M首月折算资费标准1990元/月，100M/100M首月折算资费标准2406.67元/月；200M/200M首月折算资费标准4073.33元/月，300M/300M首月折算资费标准6573.33元/月，500M/500M首月折算资费标准10740元/月，800M/800M首月折算资费标准18240元/月）。**
2. **原精品专线套餐客户变更为本套餐的，如客户原精品专线套餐规则为立即生效的，原套餐到期后转为次月生效新套餐（年付），则变更当月：老套餐到期后至新套餐生效前的实际使用天数按原套餐费用计，即变更当月账单收取原套餐按天使用费用和次月生效的新套餐年付费用。**
3. 本规则期满后，为保障客户通信的连续性，在客户未办理业务注销（拆机）手续前，中国电信上海公司不得擅自终止向客户提供通信服务。中国电信上海公司应继续为客户提供通信服务，双方按以下约定办理：

       2. **本规则到期前30日内，若客户不作资费套餐的变更，则本营销规则自动延展12个月（1年），延展次数不限。**
       3. 若中国电信上海公司不能向客户提供原资费套餐，有义务提前一个月通知客户，重新签订新的规则。
