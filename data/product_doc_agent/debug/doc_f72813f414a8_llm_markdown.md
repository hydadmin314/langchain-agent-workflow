**中国电信股份有限公司上海分公司**

**互联网专线之“精品专线”营销活动规则(2025/B)**

1. **本规则月付套餐和年付套餐协议期为一年，两年付套餐协议期为二年，均自客户所选择的基础套餐内宽带产品完工之次月1日起算，首月资费以套餐月基本费为基数按天折算。年付、两年付方式用户的付费周期也从宽带产品完工之次月开始，首月资费以同档次月付套餐资费为基数按天折算。**
2. **原精品专线套餐客户变更为本套餐的，如客户原精品专线套餐规则为立即生效的，原套餐到期后转为次月生效新套餐（年付），则变更当月：老套餐到期后至新套餐生效前的实际使用天数按原套餐费用计，即变更当月账单收取原套餐按天使用费用和次月生效的新套餐年付费用。**
3. 本规则期满后，为保障客户通信的连续性，在客户未办理业务注销（拆机）手续前，中国电信上海公司不得擅自终止向客户提供通信服务。中国电信上海公司应继续为客户提供通信服务，双方按以下约定办理：
   * + 1. 客户可选择使用标准资费或办理中国电信上海公司提供的各类资费套餐；
       2. **本规则到期前30日内，若客户不作资费套餐的变更，则本营销规则自动延展12个月/24个月（1年/2年），延展次数不限。**
       3. 若中国电信上海公司不能向客户提供原资费套餐，有义务提前一个月通知客户，重新签订新的规则。
4. 营销规则期满后，客户不续约的，可以办理相关产品注销手续**（需归还中国电信领航者Navigator定制网关（A8-C定制终端）并保证该设备的完好可用，不能归还的，客户需向中国电信上海公司支付该终端设备费用：1000元/台）**。
5. 参加本套餐的客户必须选择基础套餐，在此基础上客户方可选择可选包或可选产品，若客户退出基础套餐，则可选包或可选产品也随之失效。
6. 仅限一线宽带加入基础套餐。若客户装有两线宽带，应分别申请加入套餐。
7. 欠费2个月以上的客户不得参加本次优惠活动；已参加中国电信上海公司宽带业务优惠活动的且仍在营销规则约束期内的客户除非退出原活动，否则不得参加本次优惠活动、享受套餐优惠；已参加中国电信上海公司可选包中相关产品营销活动的且仍在营销规则约束期内的客户，不能选择与该产品有关的可选优惠。
8. **如客户办理宽带业务注销（拆机）、过户、停机保号等业务的，视为客户主动退出本营销活动。**
9. 天翼安全大脑可选包协议期12个月。**自安全大脑产品完工之次月1日起算，首月资费以可选包月基本费为基数按天折算。因客户原因退出本活动或导致本活动提前终止的,客户应结清之前已使用的费用及违约金, 剩余协议期6个月（含）以下的，收取1个月可选包标准月基本费的违约金，剩余协议期6个月以上的，收取剩余协议期的月份/12（向上取整）\*2个月可选包标准月基本费。套餐协议期期满但天翼安全大脑可选包协议期未满的，若客户要求拆除套餐的，天翼安全大脑可选包一并拆除，客户仍需按本条规则支付天翼安全大脑可选包的违约金。领用过相关设备的，客户须归还设备并保证设备的完好。**
