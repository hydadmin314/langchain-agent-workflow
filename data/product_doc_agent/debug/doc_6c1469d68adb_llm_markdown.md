**中国电信股份有限公司上海分公司**

**互联网专线之“智能专线”营销活动规则(2022/D)**

1. **本规则月付套餐和年付套餐协议期为一年，两年付套餐协议期为二年，均自客户所选择的基础套餐内宽带产品完工之次月1日起算，首月资费以套餐月基本费为基数按天折算。年付、两年付方式用户的付费周期也从宽带产品完工之次月开始，首月资费以同档次月付套餐资费为基数按天折算。**
2. 本规则期满后，为保障客户通信的连续性，在客户未办理业务注销（拆机）手续前，中国电信上海公司不得擅自终止向客户提供通信服务。中国电信上海公司应继续为客户提供通信服务，双方按以下约定办理：
   * + 1. 客户可选择使用标准资费或办理中国电信上海公司提供的各类资费套餐；
       2. **本规则到期前30日内，若客户不作资费套餐的变更，则本营销规则自动延展12个月/24个月（1年/2年），延展次数不限；其中本地代维-现场服务不做延展。**
       3. 若中国电信上海公司不能向客户提供原资费套餐，有义务提前一个月通知客户，重新签订新的规则。
3. **营销规则期满后，客户不续约的，可以办理相关产品注销手续（若有天翼领航定制终端设备的，需归还该设备并保证设备的完好可用，不能归还的，客户需向中国电信上海公司支付A8-C定制终端费用：1000元/台）。**
4. 参加本套餐的客户必须选择基础套餐，在此基础上客户方可选择可选包或可选产品，**若客户退出基础套餐，则可选包或可选产品也随之失效。套餐中包含的天翼企业云盘资源在规则有效期满后资源自动释放，数据不做保留，客户需提前做好数据迁移备份工作，一旦资源释放所有数据将全部清除无法还原。**
5. 仅限一线宽带加入主套餐。若客户装有两线宽带，应分别申请加入套餐。
6. 关于可选产品“智能专线入云专线”功能：
   * + 1. 客户可在基础套餐基础上，选择叠加“智能专线入云专线”可选产品。**开通“智能专线入云专线”功能后，中国电信上海公司将在基础套餐包含的智能专线上网专线基础上，为客户另行提供带宽弹性可调的上网及逻辑隔离的安全上云通道，客户可按订购的入云专线上下行速率访问天翼云。**
       2. **可选产品开通后立即生效，生效当月按天折算收取可选产品资费；变更和退订立即生效，生效当月按天折算收取可选产品资费。本功能基于基础套餐中包含的智能专线上网专线，如客户退出基础套餐，本功能自动失效。**
7. 欠费2个月以上的客户不得参加本次优惠活动；已参加中国电信上海公司宽带业务优惠活动的且仍在营销规则约束期内的客户除非退出原活动，否则不得参加本次优惠活动、享受套餐优惠；已参加中国电信上海公司可选包中相关产品营销活动的且仍在营销规则约束期内的客户，不能选择与该产品有关的可选优惠。
8. 如客户办理宽带业务注销（拆机）、过户、停机保号等业务的，视为客户主动退出本营销活动。
9. **客户申请订购天翼企业云盘可选包，即默认认可《中国电信天翼云用户协议》，协议内容详见以下网址：http://www.ctyun.cn/terms。**
