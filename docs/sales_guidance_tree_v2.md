# 销售套餐需求引导树 v2

这版引导树按新的思维导图收敛为三个销售入口：上网、组网、运营商资源。它用于销售前置沟通和 Agent 追问，不直接替代底层产品资料分类。

## 1. 总入口问题

第一问先锁定客户这次主要想解决的问题：

- 是要给办公室、门店或服务器办上网？
- 是总部、分公司、门店之间要互联组网？
- 还是先确认某个地址更适合走哪个运营商资源？

如果客户只说“想办网络”“想了解套餐”，优先追问：

- 使用地点是办公室、门店商铺，还是服务器/机房场景？
- 大概多少人或多少终端使用？
- 是否需要固定公网 IP，也就是长期不变、可供外部访问的网络地址？
- 预算大概在哪个区间，是优先便宜，还是优先稳定和质量？

## 2. 上网场景

### 2.1 小微门店上网

判断条件：

- 路边店、沿街店铺、小商场、单门店、小微经营。
- 5 人以内或约 5 个终端。
- 预算 3000 元以内。
- 主要诉求是基础上网、收银、外卖、Wi-Fi、日常经营。

引导问题：

- 门店是在路边、沿街、小商场，还是其他商业场所？
- 大概几个终端使用？收银、外卖平台、监控和顾客 Wi-Fi 是否都要走这条网络？
- 预算是否希望控制在 3000 元以内？
- 是否需要固定电话或固定公网 IP？如果只是收银和日常上网，一般先按不需要固定 IP 判断。

产品方向：

- 主推：旺铺宽带、开店宝宽带。
- 备选：智联（沃商铺）。

### 2.2 中小办公室动态 IP 上网

判断条件：

- 5 到 50 人办公上网。
- 不需要固定公网 IP，或客户没有提到服务器/网站对外访问。
- 预算大致在 6880-10880 元或 5000-12000 元区间。
- 关注办公稳定性、日常 SaaS、视频会议、文件收发。

引导问题：

- 办公室大概多少人使用？是否在 5 到 50 人之间？
- 是否只是员工日常上网，还是有服务器、官网、远程访问需要固定出口？
- 预算更接近 5000-12000 元，还是另有明确上限？
- 主要应用是普通办公、视频会议、大文件，还是访问业务系统？

产品方向：

- 主推：智云上海专线、商企云宽。
- 备选：智享（沃快车）。

### 2.3 固定 IP 少量场景

判断条件：

- 明确需要固定公网 IP。
- IP 数量不超过 13 个，或客户只说需要 1 个/少量固定 IP。
- 用于官网、服务器对外、远程访问、固定出口、直播、视频会议或高质量互联网接入。
- 高质量专线预算通常高于普通宽带，例如年费 2 万以上或 200M 以上档位。

引导问题：

- 固定公网 IP 是用于服务器对外、官网备案、远程访问，还是办公固定出口？
- 需要几个固定公网 IP？是 1 个、几个，还是十几个以内？
- 带宽大概需要多少？如果有直播、高清视频会议或大文件，是否要 200M 以上？
- 是否涉及网站备案或服务器合规材料？

产品方向：

- 主推：精品专线。
- 备选：智光（沃动车）。

### 2.4 固定 IP 大段场景

判断条件：

- 固定公网 IP 数量大于 13 个。
- 典型诉求是 32 个固定 IP、大段地址、服务器集群、对外服务规模较大。
- 预算可能从几千到几十万元/月，需要人工确认资源和报价。

引导问题：

- 需要固定 IP 的准确数量是多少？是否类似 32 个或更多？
- IP 用于服务器集群、业务对外，还是其他场景？
- 是否需要 BGP、多运营商访问质量或更高路由能力？
- 月预算大概是多少？能否接受按资源和地址段单独核价？

产品方向：

- 主推：IPMAN。
- 备选：沃专线。

## 3. 组网场景

### 3.1 点对点

判断条件：

- 两个地点互联，例如总部到仓库、办公室到机房。
- 需要稳定专线或纯内网互通。

引导问题：

- 是两个点之间互联，还是多个点互联？
- 两个地址分别在哪里？是否都在上海本地，还是跨省/国内异地？
- 需要纯内网互通，还是同时需要互联网出口？
- 每个点大概需要多少带宽？业务对时延和稳定性要求高不高？

产品方向：

- 本地 IPRAN：相对便宜。
- 本地国内 MSTP：目前使用较多，后续可能升级到 OTN。
- 本地国内 OTN：高等级、大带宽、重要业务传输场景。

### 3.2 点对多

判断条件：

- 总部到多个分支、多个门店或多个仓库。
- 可以评估“爪形/星型”拓扑，例如要 2 根 IPRAN，比三点全网状 3 根线路更省。

引导问题：

- 一共有几个站点？是总部连多个分支，还是每个点之间都要互通？
- 是否可以接受总部作为中心点的“爪形/星型”结构？
- 分支之间是否必须彼此互通，还是只需要访问总部系统？
- 每个站点带宽是否一致，还是总部带宽更高？

产品方向：

- 少量分支且可中心化：优先评估 IPRAN 爪形/星型方案。
- 多点互通或更复杂组网：评估 MPLS-VPN、MSTP-VPN、SD-WAN。

### 3.3 智能组网

判断条件：

- 客户需要多点网络管理、快速开通、设备化接入、或已有宽带上叠加组网。
- 需要判断是“拉线型”还是“设备上网型”。

引导问题：

- 每个点是否已经有可用宽带？是否希望通过设备接入后组网？
- 是必须重新拉专线，还是可以基于现有互联网宽带做组网？
- 是否需要固定电话类似的拉线方式，还是设备插上宽带即可？
- 是否需要统一管理、故障切换、应用加速或可视化运维？

产品方向：

- 需要拉线：MSTP-VPN。
- 已有上网线路、通过设备提供组网：SD-WAN。

## 4. 运营商资源场景

运营商资源不是产品承诺，只用于推荐前的资源倾向和人工核实顺序。

判断与引导：

- 电信：南方区域覆盖强，可作为多数南方办公、专线、组网场景的优先核实方向。
- 联通：商务楼、园区覆盖较常见，小区覆盖比例较低，适合商务楼/园区先核。
- 移动：小区、有线通、长城通相关资源可先核。

引导问题：

- 安装地址在哪个城市、区、楼宇或园区？是否能提供具体门牌或机房位置？
- 场地类型是商务楼、园区、商铺、小区，还是自建园区/厂房？
- 客户是否已有电信、联通或移动线路？有没有明确运营商偏好？
- 如果首选运营商资源不可用，是否接受备选运营商方案？

风险边界：

- 覆盖率只能作为经验倾向，不能直接承诺可装、可开通或价格。
- 具体地址必须做资源核查后再确认。
