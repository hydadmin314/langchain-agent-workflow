# 新版用户需求引导书

适用范围：销售在客户尚未明确产品名称时，用本引导书快速判断客户属于“上网”还是“组网”，并通过少量关键问题收敛到可推荐套餐或资源核实方向。

新版只分两个主模块：

- 上网
- 组网

运营商资源不作为主入口，只作为最后的资源核实原则。默认优先推荐电信；如果客户明确要求联通，需要核实客户办公楼、园区或地址是否有联通光纤资源。

## 一、总入口问题

先判断客户需求属于哪一类：

1. 客户是要给办公室、门店、商铺、服务器办理上网？
2. 还是要让总部、分公司、仓库、门店等多个地点之间互联组网？

如果客户只说“想办网络”“想了解套餐”“网络慢”，不要直接推荐产品，先问：

1. 这个网络主要是用于上网，还是多个地点之间互联？
2. 如果是上网，大概多少人或多少终端使用？
3. 如果是上网，是否需要固定公网 IP？固定公网 IP 可以理解为长期不变、可供外部访问的互联网地址。
4. 如果是组网，是点对点、点对多，还是多个点之间都要互通的网状结构？
5. 客户有没有明确预算，或者是优先便宜还是优先稳定？

## 二、主流程判断

### 1. 上网

IF 客户需求是办公室上网、门店上网、商铺宽带、员工办公、服务器对外访问、官网备案、固定公网 IP、高质量互联网接入

THEN primary_scene = “上网”

AND 继续确认：

- 客户规模多少人或多少终端？
- 是否需要固定公网 IP？
- 是否需要语音/固定电话？
- 预算大概是多少？
- 对稳定性和带宽有没有特别要求？

### 2. 组网

IF 客户需求是总部和分公司互联、门店互联、仓库互联、内网互通、专线互联、点对点、点对多、多点组网、SD-WAN

THEN primary_scene = “组网”

AND 继续确认：

- 是点对点、点对多，还是网状结构？
- 一共有几个站点？
- 是只需要访问总部，还是各分支之间也要互通？
- 是否已有宽带，还是必须重新拉专线？
- 每个点大概需要多少带宽？

### 3. 办理流程

IF 用户需求是移机、过户、改套餐、改账单、付款方式变更、工商更名、拆机、撤单、续约、退款、材料、担保、授权、办理流程

THEN 进入“办理流程/材料清单模式”，不进入新套餐推荐。

## 三、上网模块

上网模块的核心判断顺序：

1. 先问客户规模：多少人、多少终端、是否门店。
2. 再问是否需要固定公网 IP。
3. 再结合预算、带宽、稳定性和运营商偏好判断套餐方向。

### 3.1 小微门店/小规模上网

判断条件：

- 路边店、沿街店铺、小商场、单门店、小微经营。
- 5 人以内或约 5 个终端。
- 预算 3000 元以内。
- 主要用于收银、外卖平台、门店 Wi-Fi、监控、日常上网。
- 通常不需要固定公网 IP。

继续问：

1. 门店是在路边、沿街、小商场，还是其他商业场所？
2. 大概几个人或几个终端使用？
3. 收银、外卖、监控和 Wi-Fi 是否都要走这条网络？
4. 预算是否希望控制在 3000 元以内？
5. 是否需要固定电话？
6. 是否有官网、服务器或远程访问需要固定公网 IP？

主产品锁定：

IF 路边店/沿街店铺/小商场 AND 5 人以内 AND 预算 3000 元以内 AND 不需要固定公网 IP

THEN 候选产品 = 旺铺宽带 / 开店宝宽带

ELSEIF 客户指定联通或已有联通资源

THEN 候选产品 = 智联（沃商铺）/ 沃商务企微宽带

ELSE 默认候选 = 旺铺宽带 / 开店宝宽带 / 商企云宽

补充规则：

IF 客户需要固定公网 IP

THEN 转入“固定 IP 上网”分支。

IF 客户是连锁多门店，需要各门店互联

THEN 同时进入“组网”模块。

### 3.2 中小办公室动态 IP 上网

判断条件：

- 5 到 50 人办公上网。
- 不需要固定公网 IP，或客户没有服务器/官网/固定出口需求。
- 预算大致在 5000-12000 元区间，也可参考 6880-10880 元区间。
- 主要用于员工日常办公、SaaS、视频会议、文件收发。

继续问：

1. 办公室大概多少人使用？是否在 5 到 50 人之间？
2. 是否只是员工日常上网？
3. 是否有服务器、官网、远程访问或固定出口需求？
4. 是否需要固定公网 IP？
5. 预算更接近 5000-12000 元，还是另有明确上限？
6. 是否需要语音或固定电话？

主产品锁定：

IF 5 到 50 人 AND 不需要固定公网 IP AND 预算在 5000-12000 元区间

THEN 候选产品 = 智云上海专线 / 商企云宽

ELSEIF 客户指定联通或已有联通资源

THEN 候选产品 = 智享（沃快车）

ELSEIF 客户强调高稳定、高质量、高保障

THEN 候选产品 = 精品专线

ELSE 默认候选 = 商企云宽 / 智云上海专线 / 商务专线

补充规则：

IF 客户需要固定公网 IP

THEN 转入“固定 IP 上网”分支。

IF 客户人数超过 50 人或业务非常关键

THEN 重点确认带宽、稳定性、是否需要更高等级专线。

### 3.3 固定 IP 上网：少量 IP

判断条件：

- 客户明确需要固定公网 IP。
- IP 数量不超过 13 个，或客户只说需要 1 个/少量固定 IP。
- 用途包括官网、服务器对外、远程访问、办公固定出口、直播、视频会议、高质量互联网接入。

继续问：

1. 固定公网 IP 用于服务器对外、官网备案、远程访问，还是办公固定出口？
2. 需要几个固定公网 IP？是 1 个、几个，还是 13 个以内？
3. 带宽大概需要多少？是否有 200M 以上要求？
4. 是否涉及网站备案？
5. 是否有直播、高清视频会议或高并发访问？

主产品锁定：

IF 固定 IP 数量 <= 13 OR 未明确为大段 IP

THEN 候选产品 = 精品专线

ELSEIF 客户指定联通或已有联通资源

THEN 候选产品 = 智光（沃动车）

ELSE 默认候选 = 精品专线 / 智光（沃动车）

补充规则：

IF 涉及网站上线或备案

THEN 补充事项 = 网站备案材料。

IF 客户后续确认需要大量固定 IP

THEN 转入“固定 IP 大段”分支。

### 3.4 固定 IP 上网：大段 IP

判断条件：

- 固定公网 IP 数量大于 13 个。
- 典型诉求是 32 个固定 IP、大段地址、服务器集群、对外业务规模较大。
- 预算、资源和地址段必须人工确认。

继续问：

1. 需要固定 IP 的准确数量是多少？是否类似 32 个或更多？
2. IP 用于服务器集群、业务对外，还是其他场景？
3. 是否需要 BGP、多运营商访问质量或更高路由能力？
4. 月预算大概是多少？
5. 是否能接受按资源和地址段单独核价？

主产品锁定：

IF 固定 IP 数量 > 13

THEN 候选产品 = IPMAN

ELSEIF 客户指定联通或已有联通资源

THEN 候选产品 = 沃专线

ELSE 默认候选 = IPMAN / 沃专线

补充规则：

IF 客户要求 BGP、多运营商质量或大段地址

THEN 标记人工核实资源、价格、合规和可开通性。

IF 客户预算不明确

THEN 不承诺价格，只提示需要按地址、带宽和 IP 数量核价。

## 四、组网模块

组网模块的核心判断顺序：

1. 先问拓扑结构：点对点、点对多、网状结构。
2. 再问站点数量和每个站点位置。
3. 再问业务互通关系：只访问总部，还是各点互通。
4. 再问线路方式：已有宽带设备组网，还是必须拉专线。
5. 最后确认带宽、稳定性、预算和资源。

### 4.1 点对点

判断条件：

- 两个地点互联。
- 例如总部到仓库、办公室到机房、两个园区互通。
- 需要稳定专线、纯内网互通或重要业务传输。

继续问：

1. 是否只有两个点互联？
2. 两个地址分别在哪里？是否都在上海本地，还是跨省/国内异地？
3. 需要纯内网互通，还是同时需要互联网出口？
4. 每个点大概需要多少带宽？
5. 业务对时延、稳定性、线路等级要求高不高？

主产品锁定：

IF 点对点 AND 预算敏感

THEN 候选产品 = 本地 IPRAN

ELSEIF 点对点 AND 当前常规专线互联

THEN 候选产品 = 本地国内 MSTP

ELSEIF 点对点 AND 高等级、大带宽、重要业务传输

THEN 候选产品 = 本地国内 OTN

ELSE 默认候选 = IPRAN / MSTP / OTN

补充规则：

IF 客户同时需要互联网出口

THEN 联动上网产品，如商企云宽、精品专线、IPMAN。

IF 客户是高等级业务

THEN 必须人工确认资源、报价、SLA 和开通周期。

### 4.2 点对多

判断条件：

- 一个总部或中心点连接多个分支、门店、仓库。
- 多数情况下分支只需要访问总部系统，不一定要彼此互通。
- 可以评估爪形/星型结构，例如总部连接两个分支，用两根线路，而不是三点全网状互联。

继续问：

1. 一共有几个站点？
2. 是否有一个总部或中心点？
3. 分支之间需要互通吗，还是只需要访问总部？
4. 是否可以接受总部作为中心点的爪形/星型结构？
5. 各站点带宽是否一致，还是总部带宽更高？

主产品锁定：

IF 少量分支 AND 可总部中心化

THEN 候选产品 = IPRAN 爪形/星型方案

ELSEIF 多点互通、总部+多分支、需要专线级组网

THEN 候选产品 = MPLS-VPN / MSTP-VPN

ELSEIF 多门店、快速开通、灵活组网

THEN 候选产品 = SD-WAN

ELSE 默认候选 = IPRAN / MPLS-VPN / MSTP-VPN / SD-WAN

补充规则：

IF 客户要求每个点之间都互通

THEN 需要提醒这更接近网状结构，线路数量和费用可能上升。

IF 客户站点数、带宽、拓扑未知

THEN 先追问站点数和是否总部中心化，不直接推荐。

### 4.3 网状结构

判断条件：

- 多个站点之间都需要互通。
- 不是只访问总部，而是 A、B、C 等各点之间都要互访。
- 复杂度、线路数量和费用通常高于点对多。

继续问：

1. 一共有几个站点？
2. 是否每个站点都需要访问其他所有站点？
3. 有没有中心总部，还是完全多点互通？
4. 每个站点带宽是否一致？
5. 是否可以接受用 VPN/SD-WAN 方式简化组网？

主产品锁定：

IF 多站点全互通 AND 要专线级内网

THEN 候选产品 = MPLS-VPN / MSTP-VPN

ELSEIF 多站点全互通 AND 希望更灵活、快速、设备化

THEN 候选产品 = SD-WAN

ELSEIF 站点数量少且可改成中心化

THEN 回到“点对多”分支评估 IPRAN 爪形/星型方案

ELSE 默认候选 = MPLS-VPN / MSTP-VPN / SD-WAN

补充规则：

IF 客户坚持网状专线

THEN 必须人工评估线路数量、资源、价格和开通周期。

IF 客户可以接受逻辑互通

THEN 优先评估 MPLS-VPN 或 SD-WAN。

### 4.4 智能组网/SD-WAN

判断条件：

- 客户需要多点网络管理、快速开通、设备化接入、云管控。
- 客户已有宽带，希望在现有线路上叠加组网。
- 需要判断是“拉线型”还是“设备上网型”。

继续问：

1. 每个点是否已经有可用宽带？
2. 是必须重新拉专线，还是可以基于现有互联网宽带做组网？
3. 是否通过设备接入后即可满足？
4. 是否需要统一管理、故障切换、应用加速或可视化运维？
5. 是否需要固定线路级别的稳定性？

主产品锁定：

IF 需要拉线或固定线路类组网

THEN 候选产品 = MSTP-VPN / MPLS-VPN

ELSEIF 已有上网线路 AND 希望通过设备提供组网

THEN 候选产品 = SD-WAN

ELSE 默认候选 = MSTP-VPN / SD-WAN

补充规则：

IF 客户没有现成宽带

THEN 需要同时评估各点上网线路。

IF 客户对稳定性要求极高

THEN 不直接承诺 SD-WAN 效果，需人工核实线路质量和设备能力。

## 五、运营商资源原则

运营商资源不是第三个主模块，只作为上网或组网推荐后的资源核实原则。

### 5.1 默认推荐电信

默认原则：

- 大多数场景优先推荐电信。
- 特别是南方区域、上海本地、政企办公、专线、组网场景，优先核实电信资源。
- 电信作为默认主推方向时，也不能直接承诺具体地址一定可装。

销售话术：

“这类需求我们一般优先按电信方向核实资源和套餐。最终能否开通，还要看具体安装地址、楼宇资源和端口情况。”

### 5.2 客户非要联通

判断条件：

- 客户明确指定联通。
- 客户已有联通资源。
- 客户因价格、集团要求或历史线路原因必须走联通。

必须核实：

1. 客户办公楼、园区或地址是否有联通光纤资源。
2. 是否有可用端口。
3. 是否支持客户所需带宽。
4. 是否支持固定公网 IP 或专线能力。
5. 如果联通资源不可用，客户是否接受电信备选。

销售话术：

“如果客户指定联通，我们需要先核实办公楼是否有联通光纤资源，以及是否有可用端口和对应带宽。联通资源确认前，不建议直接承诺套餐可办。”

### 5.3 移动作为备选

判断条件：

- 客户地址在小区、住宅类区域、部分沿街商铺。
- 客户已有移动、有线通、长城通相关资源。
- 电信或联通资源不可用时可作为备选核实。

销售话术：

“移动可以作为备选方向核实，尤其是小区、住宅类或已有移动资源的地址。但是否能满足政企上网或组网要求，仍要看具体资源和产品能力。”

## 七、最低推荐条件

### 7.1 上网

最低条件：

- 能判断客户是办公室、门店、服务器或固定 IP 上网场景。
- 至少知道客户规模或是否需要固定公网 IP。

必须追问：

- 多少人或多少终端使用？
- 是否需要固定公网 IP？
- 预算范围。

可先假设：

- 未提固定 IP 时，暂按不需要固定公网 IP。
- 未提语音时，暂按不需要固定电话。

### 7.2 组网

最低条件：

- 能判断客户是两个或多个地点互联。
- 至少知道拓扑结构是点对点、点对多还是网状结构。

必须追问：

- 点对点、点对多，还是网状结构？
- 一共有几个站点？
- 是否只访问总部，还是各分支之间也要互通？
- 是否已有宽带或必须拉专线？

可先假设：

- 未明确带宽时，暂按站点数量和业务重要性初步评估。

### 7.3 运营商资源

最低条件：

- 知道客户地址或楼宇/园区/小区类型。

默认原则：

- 默认优先电信。
- 客户指定联通时，必须核实办公楼是否有联通光纤资源。
- 资源未核实前，不承诺可装、价格或开通周期。

## 八、风险表达边界

以下内容必须人工确认，Agent 和销售话术不得直接承诺：

1. 具体地址是否可装、是否有端口、是否可开通。
2. 联通办公楼是否有光纤资源。
3. 固定公网 IP 数量、地址段、BGP、IPMAN 资源。
4. 精品专线、OTN、MSTP、IPRAN 等专线资源和报价。
5. 网站备案、服务器对外、PCDN、大流量分发等合规场景。
6. 价格有效期、协议期、优惠、折扣、开通时效。

推荐话术中可以说：

- “可作为候选方向。”
- “建议优先核实电信资源。”
- “如果客户指定联通，需要先核实办公楼是否有联通光纤资源。”
- “需要结合具体地址、资源和资费人工确认。”
- “如果固定 IP 数量超过 13 个，建议优先按 IPMAN 方向核价。”

推荐话术中不要说：

- “一定能装。”
- “保证满足。”
- “肯定覆盖。”
- “联通一定有资源。”
- “价格就是这个。”

## 九、典型问法模板

### 9.1 泛网络需求

客户说：“想了解网络套餐。”

销售追问：

“我先帮您判断是上网还是组网。这个网络主要是给办公室/门店日常上网，还是多个地点之间互联？如果是上网，大概多少人或多少终端使用；如果是组网，是点对点、点对多还是多点全互通？”

### 9.2 办公室上网

客户说：“办公室要办宽带。”

销售追问：

“办公室大概多少人使用？是否需要固定公网 IP，比如官网、服务器或远程访问要长期用同一个固定地址？预算大概在什么范围？”

### 9.3 小微门店上网

客户说：“沿街小店，收银和 Wi-Fi 要用，预算不高。”

销售追问：

“这类先按小微门店上网判断。门店大概几个终端使用？预算是否希望控制在 3000 元以内？收银、外卖、监控和 Wi-Fi 是否都要走同一条网络？”

### 9.4 固定 IP 上网

客户说：“服务器要对外访问，需要固定 IP。”

销售追问：

“固定公网 IP 是关键条件，我再确认下：需要几个固定 IP？是官网/服务器对外访问，还是办公固定出口？是否涉及网站备案？”

### 9.5 点对点组网

客户说：“总部和仓库要互通。”

销售追问：

“这是点对点组网。我再确认下：两个点分别在哪里？是纯内网互通还是也要互联网出口？每个点大概需要多少带宽？”

### 9.6 点对多组网

客户说：“总部要连两个分支。”

销售追问：

“这是点对多组网。我再确认下：分支之间需要互通吗，还是只要访问总部？是否可以总部作为中心点做爪形/星型结构？每个站点大概需要多少带宽？”

### 9.7 网状组网

客户说：“三个办公室之间都要互相访问。”

销售追问：

“这更像网状组网。我再确认下：每个办公室都需要访问另外两个办公室吗？有没有一个总部中心点？如果能改成总部中心化，线路数量和费用可能更好控制。”

### 9.8 客户指定联通

客户说：“客户非要联通。”

销售追问：

“联通方向可以核实，但需要先确认客户办公楼或园区是否有联通光纤资源，以及是否有可用端口和对应带宽。如果联通资源不满足，是否可以接受电信备选？”
